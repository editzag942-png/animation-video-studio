# Animation Video Studio

A free, mobile-friendly starter workspace for planning animated reels.

## Current features
- Script input and character descriptions
- Scene breakdown from dialogue/script
- Reusable animation prompt
- JSON project export
- Responsive dark interface and basic offline caching

## Important limitation
This is a planning starter, not an AI video generator. It does not render MP4, animate characters, or upload audio. No paid API is included.

## Deploy
Enable GitHub Pages for the `main` branch, root folder. Then open the Pages URL on Android Chrome. You can use Chrome's menu → Add to Home screen.
